# TEZAS — QR-меню

Статический сайт без сборки: `index.html`, `styles.css`, `app.js`, `data.js`, папки `img/` и `fonts/`.

- **Цены и позиции** — только в `data.js` (казахский `kk` и русский `ru`).
- **Фото** — `img/<имя>.webp`, имя указывается в поле `img` позиции.
- **Проверить локально:** `python3 -m http.server` в этой папке → http://localhost:8000
- Для публикации подойдёт любой статический хостинг (Vercel, Netlify, GitHub Pages).
